# باربی باش — نسخه بهبود یافته (Improved)

پروژه استاتیک بهبود یافته فروشگاه مکمل‌های گیاهی لاغری **باربی باش**.

## تغییرات و بهبودها

### طراحی و UI
- فایل CSS مشترک `css/improvements.css` با متغیرهای یکپارچه، انیمیشن‌های نرم‌تر، سایه بهتر و ریسپانسیو قوی‌تر
- بهبود استایل دکمه‌ها، کارت‌ها، بج سبد خرید و فوتر
- Toast نوتیفیکیشن مدرن برای اضافه شدن به سبد

### ساختار کد
- فایل `js/common.js` برای مدیریت مشترک هدر/فوتر/بنر و توابع کمکی
- بارگذاری consistent اسکریپت‌ها در همه صفحات
- بهبود accessibility (focus states، aria-labelها)

### SEO و متا
- متا تگ‌های کامل‌تر (description، keywords، author، robots)
- Open Graph tags
- theme-color برای موبایل

### عملکرد و تجربه کاربری
- حفظ کامل سیستم سبد خرید مبتنی بر localStorage
- fallback زیبا برای تصاویر محصول (آیکون Font Awesome)
- انیمیشن‌های reveal و hover بهبود یافته

## نحوه استفاده

1. فایل‌ها را از حالت فشرده خارج کنید.
2. کل پوشه را روی هر هاست استاتیک (GitHub Pages، Netlify، Vercel، یا سرور معمولی) آپلود کنید.
3. برای تست محلی می‌توانید از Live Server یا `npx serve .` استفاده کنید.

## ساختار پوشه

```
barbisite-improved/
├── index.html
├── shop.html
├── product.html
├── cart.html
├── about.html
├── faq.html
├── contact.html
├── css/
│   └── improvements.css
├── js/
│   ├── pricing.js      # قیمت‌ها و تخفیف سراسری
│   ├── products.js     # داده‌های محصولات + توابع سبد
│   └── common.js       # UI مشترک و toast
└── images/
    └── logo/
```

## تنظیمات سریع

- **تخفیف سراسری**: در `js/pricing.js` مقدار `GLOBAL_DISCOUNT` را تغییر دهید.
- **شماره واتساپ/تلگرام**: در `js/pricing.js` بخش `ADVISOR` و همچنین در `js/common.js`.
- **قیمت محصولات**: فقط در `PRICING` داخل `pricing.js`.

---

نسخه مدرن (React + Vite + Tailwind) در حال تکمیل موازی است و در آپدیت بعدی اضافه خواهد شد.
